# Overview

This project is my first step in building a personal software portfolio.  
It contains a simple **Hello World** program, which demonstrates my ability to set up a development environment, write basic code, and publish it to GitHub.  
The purpose of creating this software is to practice the fundamentals of programming and version control, while laying the foundation for more advanced projects in the future.  

[Software Demo Video](https://youtu.be/4TsELIeypO8)

# Development Environment

- **Editor/IDE:** Visual Studio Code  
- **Programming Language:** Python (prints "Hello World" to the console)  
- **Version Control:** Git & GitHub  
- **Operating System:** Windows 10
